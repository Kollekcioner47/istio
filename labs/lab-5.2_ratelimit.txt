ТЕОРИЯ ЗА 5 МИНУТ
  Локальный лимит считает каждый прокси сам, по token bucket: max_tokens, tokens_per_fill
  и fill_interval. Внешних сервисов нет, но лимит действует на каждый под gateway
  отдельно. Глобальный лимит считает общий счётчик вне прокси: Envoy по gRPC просит
  квоту у сервиса ratelimit (envoyproxy/ratelimit), тот хранит счётчики в Redis.
  Лимиты описываются дескрипторами: domain и пары ключ/значение, например key PATH.

  Оба варианта включаются через EnvoyFilter — вставку конфигурации Envoy в mesh.
  Имена фильтров и поля patch берутся из API Envoy, а не Istio, поэтому после
  обновления Istio такие фильтры перепроверяют. Для gateway patch применяется к
  контексту GATEWAY и фильтру http_connection_manager.

  Lua — фильтр envoy.filters.http.lua: код исполняется на запросе или ответе. В Envoy
  1.33 поле inline_code устарело, код передаётся через default_source_code.

ШАГ 3. Локальный лимит: token bucket в gateway

    k1 apply -f - <<'EOF'
apiVersion: networking.istio.io/v1alpha3
kind: EnvoyFilter
metadata:
  name: local-ratelimit-httpbin
  namespace: istio-system
spec:
  workloadSelector: {labels: {istio: ingressgateway}}
  configPatches:
  - applyTo: HTTP_FILTER
    match:
      context: GATEWAY
      listener:
        filterChain:
          filter:
            name: "envoy.filters.network.http_connection_manager"
            subFilter:
              name: "envoy.filters.http.router"
    patch:
      operation: INSERT_BEFORE
      value:
        name: envoy.filters.http.local_ratelimit
        typed_config:
          "@type": >-
            type.googleapis.com/envoy.extensions.filters.http.local_ratelimit.v3.LocalRateLimit
          stat_prefix: httpbin-local-ratelimit
          token_bucket: {max_tokens: 5, tokens_per_fill: 5, fill_interval: 60s}
          filter_enabled:
            runtime_key: local_rate_limit_enabled
            default_value: {numerator: 100, denominator: HUNDRED}
          filter_enforced:
            runtime_key: local_rate_limit_enforced
            default_value: {numerator: 100, denominator: HUNDRED}
          response_headers_to_add:
          - {append: false, header: {key: x-local-rate-limit, value: "true"}}
EOF
  ЗАЧЕМ: фильтр вставляется перед router и считает запросы на подах gateway.
  ВЫ УВИДИТЕ: envoyfilter.networking.istio.io/local-ratelimit-httpbin created.
  ПРОВЕРИТЬ НА СТЕНДЕ: patch для GATEWAY собран по образцу глобального лимита из
  документации 1.25; локальный пример документации показан для SIDECAR_INBOUND.

    sleep 10

    GW=$(k1 get pod -n istio-system -l istio=ingressgateway \

    istioctl proxy-config listener "$GW" -n istio-system -o json |
      grep -c '"name": "envoy.filters.http.local_ratelimit"'
  ВЫ УВИДИТЕ: 1 — фильтр появился в цепочке фильтров. Без stat_prefix Envoy

ШАГ 4. Поднимаем инфраструктуру глобального лимита

    k1 apply -n httpbin -f - <<'EOF'
apiVersion: v1
kind: ConfigMap
metadata: {name: ratelimit-config, namespace: httpbin}
data:
  config.yaml: |
    domain: httpbin
    descriptors:
    - key: PATH
      value: "/api/get"
      rate_limit: {unit: minute, requests_per_unit: 2}
    - key: PATH
      rate_limit: {unit: minute, requests_per_unit: 100}
---
apiVersion: v1
kind: Service
metadata: {name: redis, namespace: httpbin}
spec:
  ports: [{name: redis, port: 6379}]
  selector: {app: redis}
---
apiVersion: apps/v1
kind: Deployment
metadata: {name: redis, namespace: httpbin}
spec:
  replicas: 1
  selector: {matchLabels: {app: redis}}
  template:
    metadata: {labels: {app: redis}}
    spec:
      containers:
      - name: redis
        image: redis:7.4-alpine
        ports: [{containerPort: 6379}]
---
apiVersion: v1
kind: Service
metadata: {name: ratelimit, namespace: httpbin}
spec:
  ports:
  - {name: http-port, port: 8080, targetPort: 8080}
  - {name: grpc-port, port: 8081, targetPort: 8081}
  - {name: http-debug, port: 6070, targetPort: 6070}
  selector: {app: ratelimit}
---
apiVersion: apps/v1
kind: Deployment
metadata: {name: ratelimit, namespace: httpbin}
spec:
  replicas: 1
  selector: {matchLabels: {app: ratelimit}}
  template:
    metadata: {labels: {app: ratelimit}}
    spec:
      containers:
      - name: ratelimit
        image: envoyproxy/ratelimit:30a4ce1a
        command: ["/bin/ratelimit"]
        env:
        - {name: LOG_LEVEL, value: debug}
        - {name: REDIS_SOCKET_TYPE, value: tcp}
        - {name: REDIS_URL, value: redis:6379}
        - {name: USE_STATSD, value: "false"}
        - {name: RUNTIME_ROOT, value: /data}
        - {name: RUNTIME_SUBDIRECTORY, value: ratelimit}
        - {name: RUNTIME_WATCH_ROOT, value: "false"}
        - {name: HOST, value: "::"}
        - {name: GRPC_HOST, value: "::"}
        ports: [{containerPort: 8080}, {containerPort: 8081}, {containerPort: 6070}]
        # subPath: иначе ratelimit читает и config.yaml, и симлинк ..data/config.yaml
        volumeMounts:
        - {name: config-volume, mountPath: /data/ratelimit/config/config.yaml, subPath: config.yaml}
      volumes:
      - name: config-volume
        configMap: {name: ratelimit-config}
EOF

  ratelimit слушает gRPC на 8081 и читает configmap при старте.

ШАГ 5. Включаем глобальный лимит на gateway

    k1 apply -f - <<'EOF'
apiVersion: networking.istio.io/v1alpha3
kind: EnvoyFilter
metadata:
  name: ratelimit-httpbin
  namespace: istio-system
spec:
  workloadSelector: {labels: {istio: ingressgateway}}
  configPatches:
  - applyTo: HTTP_FILTER
    match:
      context: GATEWAY
      listener:
        filterChain:
          filter:
            name: "envoy.filters.network.http_connection_manager"
            subFilter:
              name: "envoy.filters.http.router"
    patch:
      operation: INSERT_BEFORE
      value:
        name: envoy.filters.http.ratelimit
        typed_config:
          "@type": type.googleapis.com/envoy.extensions.filters.http.ratelimit.v3.RateLimit
          domain: httpbin
          failure_mode_deny: true
          timeout: 10s
          rate_limit_service:
            grpc_service:
              envoy_grpc:
                cluster_name: outbound|8081||ratelimit.httpbin.svc.cluster.local
                authority: ratelimit.httpbin.svc.cluster.local
            transport_api_version: V3
  - applyTo: VIRTUAL_HOST
    match:
      context: GATEWAY
      routeConfiguration:
        vhost:
          name: ""
          route: {action: ANY}
    patch:
      operation: MERGE
      value:
        rate_limits:
        - actions:
          - request_headers:
              header_name: ":path"
              descriptor_key: "PATH"
EOF
  ЗАЧЕМ: один объект, два патча: первый вставляет фильтр, второй задаёт дескриптор.
  ВЫ УВИДИТЕ: envoyfilter.networking.istio.io/ratelimit-httpbin created.

    sleep 10

    for i in $(seq 1 3); do
      curl -s -o /dev/null -w "%{http_code} " "http://$INGRESS_HOST/api/get"
    done
    echo
  ВЫ УВИДИТЕ: 200 200 429 — при лимите 2 в минуту.
ШАГ 6. Добавляем свой заголовок Lua-фильтром

  Убираем глобальный лимит, чтобы 429 не мешал проверке заголовка:
    k1 delete envoyfilter ratelimit-httpbin -n istio-system
    sleep 5

    k1 apply -f - <<'EOF'
apiVersion: networking.istio.io/v1alpha3
kind: EnvoyFilter
metadata:
  name: lua-httpbin
  namespace: istio-system
spec:
  workloadSelector: {labels: {istio: ingressgateway}}
  configPatches:
  - applyTo: HTTP_FILTER
    match:
      context: GATEWAY
      listener:
        filterChain:
          filter:
            name: "envoy.filters.network.http_connection_manager"
            subFilter:
              name: "envoy.filters.http.router"
    patch:
      operation: INSERT_BEFORE
      value:
        name: envoy.lua
        typed_config:
          "@type": type.googleapis.com/envoy.extensions.filters.http.lua.v3.Lua
          default_source_code:
            inline_string: |
              function envoy_on_response(response_handle)
                response_handle:headers():add("x-gateway-lua", "istio-1.25.2")
              end
EOF
  ЗАЧЕМ: Lua-код выполняется в Envoy и добавляет заголовок в ответ.
  ВЫ УВИДИТЕ: envoyfilter.networking.istio.io/lua-httpbin created.
  ПРОВЕРИТЬ НА СТЕНДЕ: имя фильтра и поле default_source_code — из API Envoy 1.33;
  отдельного примера в документации Istio для Lua нет.

    sleep 10

    curl -s -D - -o /dev/null "http://$INGRESS_HOST/api/get" | grep -i x-gateway-lua
  ВЫ УВИДИТЕ: x-gateway-lua: istio-1.25.2.
ПРОВЕРКА РЕЗУЛЬТАТА
    curl -s -o /dev/null -w "%{http_code}\n" "http://$INGRESS_HOST/api/get"
    curl -s -D - -o /dev/null "http://$INGRESS_HOST/api/get" | grep -ci x-gateway-lua
  ВЫ УВИДИТЕ: 200 и 1 — заголовок x-gateway-lua есть в каждом ответе.
ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК

ПРОБЛЕМА: глобальный лимит отвечает 500 вместо 429.
ПРИЧИНА: фильтр не может получить квоту: сервис ratelimit недоступен, а при
failure_mode_deny: true недоступность превращается в отказ.
ЧТО ДЕЛАТЬ:
  1. Проверить поды: k1 get pods -n httpbin -l app=ratelimit.
  2. Посмотреть логи: k1 logs -n httpbin deploy/ratelimit --tail=20.
  3. Сверить cluster_name в EnvoyFilter: outbound|8081||ratelimit.httpbin.svc.cluster.local.

ПРОБЛЕМА: 429 не наступает, все запросы 200.
ПРИЧИНА: EnvoyFilter не применился (не та метка селектора, не тот context), либо
дескриптор не совпал: в конфиге value "/api/get", а :path приходит с query-строкой.
ЧТО ДЕЛАТЬ:
  1. Проверить фильтр: istioctl proxy-config listener "$GW" -n istio-system -o json
     | grep -c ratelimit.
  2. Смотреть логи ratelimit: там виден пришедший дескриптор.
  3. Запросить ровно /api/get без параметров и завершающего слэша.

ПРОБЛЕМА: заголовка x-gateway-lua нет в ответе.
ПРИЧИНА: Lua-фильтр вставлен не в ту цепочку, либо в коде ошибка и Envoy его не
применил.
ЧТО ДЕЛАТЬ:
  1. Проверить фильтр: istioctl proxy-config listener "$GW" -n istio-system -o json
     | grep -c envoy.lua.
  2. Смотреть логи: k1 logs -n istio-system -l istio=ingressgateway -c istio-proxy --tail=20.
  3. Пересоздать: k1 delete envoyfilter lua-httpbin -n istio-system и apply снова.

ДОПОЛНИТЕЛЬНОЕ ЗАДАНИЕ
  Сделайте лимит по пользователю: добавьте в configmap дескриптор с key USER и
  лимитом 1 в минуту, а в EnvoyFilter замените action на request_headers с
  header_name x-user и descriptor_key USER. Три запроса от alice дают 200, 200, 429.
